SMS MANAGEMENT SYSTEM - PHP + MySQL

SETUP:
1. Install/start XAMPP.
2. Start Apache and MySQL.
3. Copy the sms_system folder into C:\xampp\htdocs\
4. Open http://localhost/phpmyadmin
5. Import database.sql (or paste its SQL into the SQL tab).
6. Open http://localhost/sms_system/login.php

LOGIN:
Username: admin
Password: 1234

FEATURES:
- Login/logout
- Add student records
- View student records
- Compose/save SMS messages
- View message history

IMPORTANT:
This college-project version stores SMS messages in MySQL.
It does NOT actually send SMS to mobile phones. Actual SMS delivery
requires an SMS gateway/API.
